# ECLYPSE 🖤

A dark-themed full-stack e-commerce web application built with the MERN stack.

## ✨ Features

- 🎬 Cinematic splash screen with animated branding
- 🔐 JWT-based authentication (Login & Signup)
- 🛍️ Product listings with category filters
- 🛒 Cart management with quantity controls
- 📦 Full cart-to-order flow
- 👤 Role-based access (User & Admin)
- 📱 Fully responsive design

## 🛠️ Tech Stack

**Frontend**
- React + Vite
- Tailwind CSS
- Framer Motion
- React Router v6
- Context API

**Backend**
- Node.js + Express
- MongoDB + Mongoose
- JWT Authentication
- bcryptjs
- REST API

## 🚀 Getting Started

### Frontend
```bash
cd frontend
npm install
npm run dev
```

### Backend
```bash
cd backend
npm install
npm run dev
```
